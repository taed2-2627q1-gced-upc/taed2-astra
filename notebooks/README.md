# Notebooks

Exploration only. Anything the pipeline or the API depends on must be moved
into `src/taed2_astra/`.

Naming: `<number>-<initials>-<topic>.ipynb`, e.g. `01-sr-data-exploration.ipynb`.

Before committing: restart the kernel, run all cells, and check the notebook
with `uv run pynblint notebooks`.
